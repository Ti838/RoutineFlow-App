# Contributing to Routine Flow

Thank you for your interest in contributing to **ROUTINE FLOW**!

## 1. Code Standards
- **Zero Lint Policy**: All code must pass `dart analyze` with 0 errors and 0 warnings.
- **Unit Testing**: Any new scheduling or business logic must be accompanied by unit tests in `test/unit/`.
- **Formatting**: Run `dart format .` before submitting commits.

## 2. Development Workflow
1. Fork and clone the repository.
2. Create a feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes with clear semantic commit messages.
4. Run `flutter test` and `dart analyze` to ensure quality standards.
5. Open a Pull Request.
